# Starter Asset Library

A CC0 asset library bundled with the iPad app as the read-only "Starter" library: things to drag
from the Assets pane into a scene. It's laid out like Blender's Essentials library (a folder of
`.blend` files and a catalog file) so it can move there later.

| Phase | Kind | Drop target | Files |
| --- | --- | --- | --- |
| 1 | Objects (mostly Geometry Nodes), sculpt bases, scenes | Anywhere in the viewport | `starter_objects.blend`, `starter_scenes.blend` |
| 2 | Materials, procedural and scanned | Onto an object | `starter_materials.blend` |
| 3 | Modifiers (Geometry Nodes groups) | Onto an object | `starter_modifiers.blend` |

## Building

The Python sources under `starter/` are the source of truth; `library/` is build output.

```sh
blender --background --factory-startup --python build_starter_library.py -- --output library
blender --background --factory-startup --python validate_starter_library.py -- --library library
```

Build one or more modules into a scratch folder while working on them (never into `library/`):

```sh
blender -b --factory-startup --python build_starter_library.py -- --output /tmp/shapes --only shapes
blender -b --factory-startup --python validate_starter_library.py -- --library /tmp/shapes \
    --contact-sheet /tmp/shapes.png
```

`--contact-sheet` writes every preview into one image, in manifest order, for reviewing them.
Use the Blender version this branch targets (5.1).

## Adding an asset

Declare it in the module for its catalog with the `@asset` decorator, return the data-block, and
build it with the helpers in `starter/nodes.py` and `starter/common.py`. See `starter/shapes.py`.

Every asset must:

- **Have metadata:** a one-sentence description, at least two search tags, and the right catalog.
- **Look good in its preview:** check the contact sheet, not just the validator.
- **Objects:** be generated by a Geometry Nodes modifier whose inputs make sense to tweak
  (named clearly, with descriptions, sensible min/max, a `Seed` where randomness is involved,
  a `Material` input, and menus for styles). Sculpt bases and human meshes are plain meshes.
  - Rest on the ground: centered on X/Y, lowest point at Z = 0 (`rest_on_ground()`). Drops
    place an object's origin on the surface under the finger.
  - Use real-world sizes in meters.
  - Stay under 50,000 triangles and 50 ms to re-evaluate at default inputs, so the iPad stays
    fluid.
- **Materials:** be procedural (no image textures, except the Scanned catalog), work without UVs
  (object or generated coordinates), and expose their tweakable inputs through a shader node group
  in front of the Material Output, so they show in Properties.
- **Modifiers:** be a Geometry Nodes group flagged as a modifier with a geometry input, that
  visibly changes the object it's dropped on.

`validate_starter_library.py` checks all of these that a script can check.
