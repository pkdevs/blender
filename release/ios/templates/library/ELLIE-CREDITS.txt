Modifications for this template:
- Migrated to Blender 5.1 and organized the original control layers as bone collections.
- Repaired missing finger-pole driver properties.
- Used Ellie's original rigged mesh hair for both viewport and render.
- Removed the unused particle hair, metarig, and embedded legacy Python scripts.
- Added application-owned native rig controls and template camera/lighting/presentation.
- Used the original pose assets for the starting pose and retained the pose library.
