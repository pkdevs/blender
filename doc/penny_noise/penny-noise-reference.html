Penny Noise

The Penny Noise feature evaluates a family of 19 procedural noise types derived from the SLA ("Smells Like Almonds") noise collection. It is available in three contexts that share a single underlying implementation:

  • Penny Noise Texture node — for shading, in EEVEE and Cycles.
  • Penny Noise Texture node (Geometry Nodes) — for geometry fields.
  • Penny Noise F-Curve modifier — for animation, in the Graph Editor.

All three produce results from the same tileable 4D improved-Perlin core and the same 19 noise types, so a look developed in one context can be reproduced in another.

Penny Noise Texture Node

The Penny Noise Texture node adds procedural SLA noise to a material or geometry field.

Shader Editor: Add ‣ Texture ‣ Penny Noise
Geometry Node Editor: Add ‣ Texture ‣ Penny Noise

Inputs

The available inputs depend on the Dimensions property.

Coordinate
Texture coordinate to evaluate the noise at. When left unconnected, the noise is evaluated in the object's local space, anchored at the object origin. Connect a Texture Coordinate or Geometry node (or any vector) to sample in a different space. Hidden when Dimensions is set to 1D.
W
The value used to evaluate the noise in the fourth dimension. Useful for animating an otherwise static pattern, or as an extra degree of variation. Available when Dimensions is 1D or 4D.
Scale
Overall scaling of the noise, as a percentage. Larger values produce larger features (the input coordinate is divided by the scale), so increasing Scale zooms into broader structure.
Scale X, Scale Y, Scale Z, Scale W
Per-axis scale multipliers applied on top of Scale, allowing the noise to be stretched or compressed independently along each axis for anisotropic patterns. Scale W affects the fourth (animation) axis.
Octaves
The number of noise octaves summed together. Higher values add progressively finer detail on top of the base pattern. Some noise types accept fractional octave counts for smooth transitions. Clamped to the range 1 to 15.
Roughness
Controls how much each successive octave contributes — effectively the amplitude falloff of higher-frequency detail. At the default of 0.5, most noise types reproduce their characteristic SLA appearance. Individual noise types interpret Roughness slightly differently (as octave falloff, gate width, fold sharpness, or displacement magnitude).
Level Min
The input value mapped to black. May be set below 0 for high-dynamic-range headroom.
Level Mid
The midtone gamma pivot, controlling midtone brightness independently of the black and white points.
Level Max
The input value mapped to white. May be set above 1 for high-dynamic-range headroom.
Period X, Period Y, Period Z, Period W
The integer tiling period along each axis, in lattice cells. The noise wraps seamlessly at these periods, so the texture tiles. Period W governs tiling in the fourth dimension, which is useful for seamless looping animation. The default is 8 on each axis.

Properties

Dimensions
The number of dimensions the noise is evaluated for. This changes which inputs are available and how the coordinate is sampled:
1D
Evaluates a one-dimensional noise from the W input only. The Coordinate input is hidden.
2D
Evaluates a two-dimensional noise from the X and Y components of Coordinate. The W input is hidden.
3D
Evaluates a three-dimensional noise from the X, Y, and Z components of Coordinate. The W input is hidden.
4D
Evaluates a four-dimensional noise from Coordinate and W together. Both inputs are available.
The default is 4D, which preserves the appearance of files created before a Dimensions value was set.
Noise Type
Which of the 19 SLA-derived noise algorithms to evaluate. See Noise Types below.
Blend Mode
How the noise is self-blended. The noise is sampled a second time at a decorrelated offset, and the two samples are combined with the chosen blend mode to produce richer variation. Normal uses the single primary sample with no self-blend. The remaining 24 options are Photoshop-style blend modes (Add, Multiply, Difference, Darken, Lighten, Color Dodge, Color Burn, Overlay, Average, Exclusion, Glow, Hard Light, Hard Mix, Linear Burn, Linear Dodge, Linear Light, Negation, Phoenix, Pin Light, Reflect, Screen, Soft Light, Subtract, Vivid Light), which are consistent across every context.

Outputs

Factor
A single-channel scalar output.
Color
A three-channel (RGB) output. Each channel is a decorrelated sample of the noise, which is useful for color variation or as a vector field.

Penny Noise F-Curve Modifier

The Penny Noise F-Curve modifier drives an animation channel with one-dimensional SLA noise. It follows the conventions of the built-in Noise modifier and adds the full Penny noise family and tone controls.

Graph Editor ‣ Sidebar ‣ Modifiers ‣ Add Modifier ‣ Penny Noise

The modifier samples the shared Penny noise field along the time axis. A Random Seed offsets the sample position on the non-time axes, so each seed produces a fully independent noise stream from the same settings.

Properties

Noise Type
Which of the 19 SLA-derived noise algorithms to evaluate. See Noise Types below.
Blend Mode
The noise self-blend mode, matching the texture node's Blend Mode (the 25 options described above).
f-Blend
How the generated noise is applied to the F-Curve value:
Replace
Adds centered noise (noise − 0.5, scaled by Strength) on top of the curve. This is the default and produces symmetric variation around the underlying value.
Add
Adds the noise value, scaled by Strength, to the curve.
Subtract
Subtracts the noise value, scaled by Strength, from the curve.
Multiply
Multiplies the curve value by the noise, scaled by Strength.
Scale
The feature size in frames. Larger values produce slower variation along the timeline.
Strength
The amplitude of the noise applied to the curve.
Offset
Shifts the sample position along the noise axis, moving the pattern earlier or later.
Octaves
The number of noise octaves. Higher values add finer detail. Clamped to the range 1 to 15.
Roughness
The amplitude falloff of higher octaves, as with the texture node.
Period
The integer tiling period along the noise axis, so the generated noise can be made to repeat.
Random Seed
Selects a fully decorrelated noise stream. Different seeds produce entirely different noise from identical settings.
Levels Min, Mid, Max
The black point, midtone gamma pivot, and white point applied to the noise, as with the texture node's Level Min / Mid / Max.

Common F-Curve Modifier controls

Influence
Blends between the unmodified and modified curve. When disabled, the modifier applies at full strength.
Restrict Frame Range
Limits the frames over which the modifier is active, with optional blend-in and blend-out ranges.

Noise Types

All contexts expose the same 19 noise types through the Noise Type selector. The internal index of each type is given in parentheses; it is useful when scripting or matching behavior across contexts.

fBm (0)
Fractional Brownian motion — a smooth, cloud-like fractal noise formed from a signed sum of Perlin octaves. The general-purpose starting point.
Turbulence (1)
Additive turbulence with a billowy, veined, marbled character. More structured and directional than fBm.
Stupl (2)
Domain-warped turbulence. Each channel is displaced by a low-frequency turbulence field before sampling, producing a swirled, flowing structure.
Luka (3)
Displacement-warped absolute-turbulence with a narrow contrast window, producing crisp ridged filaments.
Blistered (4)
Adaptive-contrast blistered turbulence. A per-channel adaptive window gates a higher-frequency inner sample, giving blister-like cells with variable edge width.
Box (5)
Axis-sliced domain-distortion noise with a boxy grain, suited to fabric, quilting, and structured surface texture.
Mod (6)
Snapped-coordinate modulation noise with a modular, patchwork character.
Nutous (7)
Self-displaced turbulence with a baked midtone, producing a nubbly, granular, clustered texture.
Cranal (8)
Folded cellular turbulence with a contrast stretch, producing bright cell interiors separated by dark edge lines.
Buya (9)
Ridge-folded, biased pseudo-fBm with an octave-aware remap that recovers high-dynamic-range detail at higher octave counts. Most detailed at moderate-to-high Octaves values.
Cell (10)
Quantized cell Perlin, producing hard-edged, blocky, Voronoi-like regions.
Displaced Turbulence (11)
An X-shifted sum of displacement-warped absolute-turbulence, with an octave-calibrated output window. Flowing and directional, like turbulence caught mid-motion.
Hama (12)
A per-octave product of gated signed turbulence, producing sparse, isolated, pinpoint features on a dark field.
Naki (13)
Displacement-warped absolute-turbulence with a smoothstep bias, giving soft, rolling, displaced waves.
Poxo (14)
Recursive absolute-turbulence accumulated as a running blend, with support for fractional octaves. Layered and fibrous.
Pezo (15)
Gated turbulence masked and dithered by a fine high-frequency detail layer, combining large soft shapes with fine surface grain.
Dents (16)
A maximum-of-octaves folded turbulence with fractional-octave support, producing dented, pitted, gouged impressions.
Sema (17)
Tightly gated turbulence with a fine dither, producing sparse, sharp-edged features on a clean field.
VL (18)
Variable-lacunarity noise — Perlin warped by Perlin — giving a rich, turbulent, marbled distortion.

Choosing a noise type

A rough grouping by visual family:

  • Smooth / fractal: fBm, Turbulence, VL
  • Warped / flowing: Stupl, Naki, Displaced Turbulence, VL
  • Ridged / crisp: Luka, Buya
  • Cellular / blocky: Cell, Cranal, Blistered
  • Sparse / spotted: Hama, Sema
  • Damaged / pitted: Dents, Nutous
  • Structured / modular: Box, Mod
  • Dual-scale / dappled: Pezo, Poxo

When in doubt, start with fBm for smooth work or Turbulence for structured work, then adjust Octaves and Roughness, which reshape every type substantially. The Levels controls retune contrast and midtones without changing the underlying pattern.

Notes

Tiling The noise is tileable in all four dimensions via the integer Period values, so textures wrap seamlessly and animations along W can be made to loop.
Consistency across contexts Results are consistent across EEVEE, Cycles (CPU and GPU), Cycles OSL, and Geometry Nodes, because these share the same 4D hash and transform chain. The F-Curve modifier and the Geometry Nodes node use a common core, so noise sampled on geometry and noise driving a curve agree exactly.
Default coordinate When the texture node's Coordinate input is unconnected, the noise is evaluated in the object's local space, so it is anchored at the object origin and scales from there rather than from a bounding-box corner.
